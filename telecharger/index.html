Comment l'installer

  1. Appuyez sur le bouton jaune ci-dessus.
  2. Quand le téléphone demande, appuyez sur « Télécharger » puis attendez la fin.
  3. Ouvrez la notification de téléchargement, ou allez dans Fichiers → Téléchargements, et appuyez sur SchoolManager-1.0.apk.
  4. Le téléphone dit « Autoriser cette source ? » : appuyez sur Paramètres, activez l'autorisation, puis revenez en arrière.
  5. Appuyez sur « Installer ». L'icône SchoolManager apparaît sur votre écran d'accueil.

⚠ Si le téléphone affiche « Application bloquée pour protéger votre appareil »

C'est la sécurité du téléphone (TECNO / HiOS), pas un défaut de l'application. L'application a été vérifiée : signature valide, aucune bibliothèque suspecte, permission Internet uniquement. Voici comment débloquer :

  1. Sur l'écran de blocage, cherchez un petit texte « Détails », « Paramètres » ou « Installer quand même » et appuyez dessus.
  2. Sinon : Paramètres → Sécurité → Play Protect → engrenage ⚙ → désactivez « Analyser les applications ».
  3. Puis Paramètres → Sécurité → Installer des applications inconnues → autorisez Chrome et Fichiers.
  4. Sur TECNO : ouvrez l'application Phone Master → Sécurité → désactivez l'analyse, puis réessayez.
